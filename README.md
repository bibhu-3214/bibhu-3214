I'm **Bibhu Prasad Sahu**, a Senior Consultant at **GyanSys Inc.** in Bangalore with nearly five years of experience building **React and TypeScript** interfaces for enterprise semiconductor applications. I care about clear data flow, honest UI states and interfaces that stay readable when the data gets heavy.

## What I work on

- **Analytics dashboards** for wafer inspection, built in a Lerna monorepo.
- **Data visualization** with D3.js and layered canvas rendering for defect data.
- **Entitlement-driven UI** that controls routes, navigation and grid columns.
- **Async data flows** in Redux with centralized token handling and request cancellation.
- **Frontend performance** through caching and state-management optimization.

## How I build

1. **Make complexity understandable.** Give components clear responsibilities and keep data flow explicit.
2. **Design around the workflow.** Think about navigation, form feedback and the transitions between states.
3. **Improve with evidence.** Measure performance, accessibility and maintainability instead of guessing.
